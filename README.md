# PruebaItRock
Proyecto WordPress
Este proyecto contiene un tema personalizado, un plugin personalizado y una sección creada con Elementor,

A continuación se describen los pasos para instalar y configurar el proyecto en local.

Requisitos
XAMPP o cualquier otro servidor local (Apache, MySQL)
WordPress
Elementor 

1. Configurar XAMPP
2. Descargar el proyecto
Descarga o clona este repositorio:
https://github.com/CammPastor/PruebaItRock.git

4. Copiar el proyecto a la carpeta de WordPress
Una vez descargado, copia los archivos editados en las carpetas correspondientes de WordPress.

Tema Hijo: Copia la carpeta del tema hijo (astra-child) en el directorio wp-content/themes/. 
Este es un tema hijo basado en el tema Astra, por lo que necesitas tener el tema Astra instalado y activado en tu instalación de WordPress.

Plugin Personalizado: Copia la carpeta del plugin (custom-post-manager) en el directorio wp-content/plugins/.

4. Activar el Tema y el Plugin
En el panel de administración de WordPress;  Apariencia > Temas y activá el tema personalizado.
Para el Plugin; Plugins > Plugins instalados y activa el plugin personalizado (custom-post-manager).

6. Configurar Elementor 
Tener Elementor instalado y activado en WordPress.
